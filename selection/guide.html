ShopSage 选品助手 使用说明（详细版）

从 1688 / 拼多多把商品采下来 → 同步到 ShopSage 后台采集箱 → 看成本与利润 → 改成交稿 → 跑 AI 分析。当前版本 V0.9.15（2026-11-13）。

开始之前一、安装与加载二、登录三、列表页采集四、详情页整页采集五、同步到后台六、成本与利润七、预计采购量与阶梯档位八、编辑成稿与一键翻译九、AI 市场分析十、更新插件十一、常见问题十二、账号与数据

开始之前，你需要准备

  • 一台电脑 + 一个 Chromium 内核浏览器：Chrome、Edge、360 安全/极速、紫鸟、站斧均可（需支持 Manifest V3，Chrome ≥ 111）。
  • 一个 ShopSage 官网账号（邮箱注册 + 邮箱验证）。插件用的就是官网这枚账号，会员、AI 点数、店铺归属与后台完全一致，不另造账号、不需要单独的插件兑换码。
  • 浏览器里已登录 1688 或拼多多。插件只读取页面已经显示的数据，不替你操作账号、不接触你的密码。
选品助手与「ShopSage 自动插件」（自动提报 / 达人邀约 / 达人 CRM / 私信 AI）是两个独立插件，可以同时装、互不影响。

一、安装与加载插件

  1. 在下载页点「高速下载（推荐）」或「境内备用下载」（两个是同一个包，MD5 一致；境内备用稍慢但国内直连稳定），得到 ShopSage-选品助手-v0.9.15.zip。
  2. 解压到一个你会长期保留的文件夹（例如桌面）。不要直接在压缩包里运行，也不要解压完就删——浏览器每次启动都要读这个文件夹。
  3. 解压后第一层就能看到 manifest.json 的那个文件夹叫 market-scout-extension。加载时选这一层，不要多进到子目录。
  4. 浏览器地址栏输入 chrome://extensions 回车（Edge 用 edge://extensions），打开右上角「开发者模式」。
  5. 点「加载已解压的扩展程序」→ 选中第 4 步那个文件夹。列表出现 ShopSage 选品助手 即安装成功。
  6. 打开 1688 或拼多多的商品列表 / 详情页，页面右侧出现「ShopSage 选品助手」面板即生效。若没出现，先按 F5 刷新该页面。
紫鸟 / 站斧等指纹浏览器如果禁止加载扩展，请把插件文件夹放进它们的扩展目录后再启用；这一步受浏览器安全策略限制，不影响其他功能。

二、登录（用官网账号）

面板顶部点「登录」→ 用 ShopSage 官网的邮箱和密码登录；没账号就在官网注册后回来登录。登录状态过期时，插件会用官网的刷新令牌静默续期，续不上会提示你重新登录。

  • 登录只决定数据进谁的采集箱——不同账号之间互相看不到，包括商品原链、采购价、成本和 AI 结论。
  • 插件不保存你的 1688 / 拼多多账号，也不代你登录任何平台。

三、在列表页采集（快，但只有基础信息）

在搜索结果页 / 类目列表页点面板上的「采集本页」，本页可见的商品会进插件的「我的选品库」，再点「同步到后台」就进 ShopSage 采集箱。

列表页能采到标题、价格、主图、商品链接、销量话术
列表页采不到SKU 规格表、图片组、属性、件重尺、物流、详情描述

所以列表页适合批量铺候选：先把一批商品收进来筛一遍，值得做的再打开详情页补全。

四、在详情页采整页（推荐，成本测算靠它）

打开某个商品的详情页（detail.1688.com/offer/… 或拼多多商品页），点「采集到选品库」。这时插件读的是页面自带的数据包，能带回：

  • 主图组与视频（首图取主图组第一张，避免列表位抓错图）
  • SKU 规格表：规格名、每个规格的进价、库存 —— 这条很关键，见第六节
  • 商品属性（材质、品牌、规格、下游平台、销售地区等页面给出的项）
  • 件重尺：重量 + 长宽高（刊登时是必填项，这里先采回来）
  • 物流与运费、认证 / 警示文字、详情描述
  • 1688 官方类目 ID（叶子 + 一级），后台不用你手抄
  • 价格档位：页面按采购量分档的价、以及「促销现价 / 非促销原价」两套价分开存
同步成功的提示里会写「整页内容：DOC·…（图 N·规格 N·属性 N…）」。如果提示「这条没有整页内容」，说明你是在列表页采的——去详情页再采一次即可补齐。

五、同步到后台采集箱

面板或「我的选品库」里点「同步到后台」，商品进入 ShopSage 官网的 AI 商品选品 → 采集箱（/selection/inbox）。

  • 同一条商品重复同步 = 更新，不会重复占位（按「账号 + 商品原链」去重）。
  • 条目只进采集它时登录的那个账号（V0.9.12 起）：每条采集记录都会记下归属账号，换账号登录后同步旧条目会被拦截并说明原因，不会把 A 账号采的商品写进 B 账号的采集箱。
  • 你手工改过的值永远不会被自动值覆盖：重复采集只补还空着的格子。
  • 列表页采集不会抹掉之前详情页采到的整页内容。

六、成本与利润：为什么是「两根轴」

一条 1688 链接的成本不是一个数，而是两件事叠在一起：

规格轴同一链接里不同规格进价差好几倍。实测一条宠物窝 40 个规格，进价 12.8 ~ 48.8 元。
数量轴同一规格买得越多单价越低（页面给的阶梯档位）。有的商品页面把「促销现价」和「非促销原价」并列给出，那不是按量分档。

后台因此这样算：

  1. 成本按规格区间取，头条利润取最贵的那个规格（保守）；界面同时摊出「最好规格 ~ 最坏规格」的利润区间。
  2. 采购价只当兜底：有 SKU 进价时以 SKU 为准，不会拿「全部规格最低价」当整条链接的成本。
  3. 促销价不参与成本计算（V0.9.11 起插件会把促销现价与非促销原价分列回传）。
  4. 运费、平台综合扣点、其他成本（退货 / 广告 / 仓储，默认 10%）按你在后台填的口径计入；ROI = 利润 ÷（采购 + 运费），不含平台扣点与其他成本。
  5. 判定只有三档：值得测试（毛利率 ≥ 30%）/ 谨慎测试（≥ 15%）/ 暂不建议。
汇率目前是静态参考值，待校准（界面会写明）。跨币种利润的绝对值请以「同一口径横向比较」为主，别当成财务数字。

七、预计采购量与阶梯档位（想算准就填它）

后台采集箱的编辑页里有一格 「预计采购量（件）」：

  • 填了：按「起订量 ≤ 预计采购量」里最高的那一档取单价，界面会写「本次按 N 件命中 ≥M 件档，单价 ¥X」。
  • 不填：按起订量档（量最少、单价最高）算 —— 这是保守口径，界面也会写明是没填才这样算。
  • 填的量没达起订量：如实标「未达起订量，按起订量档算」，不会编一个更低的价给你。
  • 页面同时给了规格进价与档位价、而两者不同源时，档位比例只按页面自己给的两档之比折算，并提示「需按实际卖的规格复核」。
  • 页面没有按量分档（各档起订量相同）时，界面直接写「这条商品页面没给采购量档位，只按规格进价区间算成本」，不会假装有几档。
这一格是你手填的值，插件重复采集不会覆盖它；清空它就退回「按起订量档」的保守算法。

八、编辑成稿与一键翻译

采集箱的编辑页照「采回来先改再发」的思路做：左边是原始采集信息（只读，永远不动），右边是成稿区。

  • 可改：标题、目标平台 / 国家 / 币种、预期售价、采购价、运费、扣点、其他成本、重量档、店铺类型、预计采购量、SKU 售卖价与库存、图片组、属性、件重尺、认证材料。
  • 保存后服务端立刻按当前口径重算利润，界面展示的是重算结果，不是采集那一刻的旧数。
  • 「一键翻译」把中文标题改写成目标市场语言（服务端代跑大模型，按后台点数结算）；译文存在目标语标题栏，原标题永远保留。
  • 详情描述出于安全不在后台直接渲染 1688 的 HTML，只给统计与源码折叠视图；提交平台时会按平台规则清洗。

九、AI 市场分析

  • 点「跑 AI 分析」由服务端代跑，模型密钥不下发到浏览器；按后台点数结算，同一条商品同一天重复点只收一次。
  • 喂给模型的输入包含：规格进价区间、页面阶梯档位、预计采购量与本次取哪一档、利润区间与判定、汇率口径，以及需要人工核对的缺口 —— 不是只喂一个最低价。
  • 硬规则：不得编造销量、搜索量、竞品价格；查不到的一律写「未知」并列出你要自己核实什么。结论同样只有三档。
  • 目前未接入联网搜索，报告里会如实标注「联网搜索：未接入」，此时只能基于商品与成本做结构化判断。

十、更新插件（每次更新后必做两步）

  1. 下载新版 zip，解压覆盖同一个文件夹（位置别变，否则要在 chrome://extensions 重新加载一次）。
  2. 在 chrome://extensions 点 ShopSage 选品助手卡片上的「重新加载」图标。
  3. 回到已打开的 1688 / 拼多多页面按 F5（切语言或改版式后建议 Ctrl+Shift+R 硬刷新）。已经打开的页面跑的还是更新前的代码，不刷新就会以为「没生效」。

如果面板提示「扩展已更新，请刷新本页面后再采集」，就是第 3 步没做。

十一、常见问题

现象原因与处理
同步后提示「这条没有整页内容」这条是列表页采的。打开商品详情页再点「采集到选品库」，然后同步。
卡片显示「价格待核对」页面数据价与可见价不一致（多为券后 / 活动价），或只取到页面可见价。插件会把两个值都留着，请在后台核对采购价。
采购价像是促销价，比规格进价低很多旧版插件（0.9.10 及以前）会把促销现价当采购价。重载最新版插件后重采该商品即可；注意后台利润走的是规格区间成本，不会被这个低价带偏。
同步时提示「这条商品是在另一个账号下采集的」本地选品库按浏览器存、不随登录账号切换；V0.9.12 起每条采集记录绑定归属账号，切回采集它时用的那个账号再同步即可。0.9.11 及以前采的老条目没有归属记录，可以同步，但插件会提示你重采一次把归属补上。
标题空着，但整页内容都采到了V0.9.13 起标题按 og:title → itemprop → meta → h1 → JSON-LD 依次兜底并留取词探针；只要图片 / SKU / 属性 / 详情图 / 描述里有真实正文，整页底稿就不再因缺标题被判空。标题仍取不到时请手工填一次，插件不会拿别的商品标题冒充。
采集后后台列表没变化没登录 / 登录过期；或点的是「采集」而不是「同步到后台」。面板会显示同步结果与编号。
详情页采不到 SKU / 图片未登录 1688 / 拼多多，或页面被平台风控拦了。刷新页面、确认已登录再采；仍失败请把面板提示截图给客服，服务端会记录诊断信息。
后台利润显示「还没测算」缺预期售价或采购价。填好并保存，服务端会重算；缺什么会明确列出来，不会用 0 冒充。
点数不足无法跑 AI / 翻译按后台价目结算，余额不足会先拦住，不会白跑；失败会原路退点。
换了电脑 / 浏览器重新加载插件并用同一个官网账号登录即可；已同步到后台的数据跟着账号走，本地「我的选品库」是浏览器本地缓存，换机需重采。

十二、账号、数据与隐私

  • 采集数据只进你自己账号（租户）的采集箱，其他账号看不到；后台接口按登录令牌回查归属，不信任请求里自报的账号信息。V0.9.12 起插件还会给每条采集记录打上归属账号，同步与 AI 分析前插件、服务端双端校验，归属不符直接拒绝。
  • 插件不读取、不保存你在 1688 / 拼多多的登录密码，只读取商品页面已经显示的数据。
  • 店铺到期或注销后，采集箱与相关数据按平台的保留策略清除；买家一类的个人信息不在采集范围内。
