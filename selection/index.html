核心能力
  • 1688 / 拼多多 列表页一键采集本页商品：标题、价格、主图一次拿齐，价格来源与「请核对」标记如实标出
  • 打开详情页可采整页底稿：主图组、视频、SKU 规格表（规格名 / 进价 / 库存）、商品属性、件重尺（重量 + 长宽高）、物流运费、认证与警示、详情描述
  • 1688 官方类目 ID（叶子 + 一级）随商品一起带回，后台不用你手抄
  • 采购价按两根轴如实带回：同一链接不同规格进价不同、页面按采购量分档的价另列，促销现价与非促销原价分开存 —— 不拿最低价冒充整条链接成本
  • 一键同步到后台「AI 商品选品 → 采集箱」；重复采集只补空着的信息，你手工改过的值不会被覆盖
  • 条目归属绑定（V0.9.12 起）：在哪个账号下采集就归属哪个账号，换账号登录后旧条目不会被同步进新账号，双端校验、归属不符直接拒绝
  • 换电脑登录（V0.9.14 起）：在已登录的那台点「获取登录码」拿到 8 位码，新电脑的插件登录框里输入即可登录，不再依赖「网页能不能联系到本机插件」；选品库按采集账号分区，A 账号采的不会出现在 B 账号里
  • 拼多多整页采集修复（V0.9.15 起）：插件的页面取数器只在页面加载那一刻注入，插件安装/更新前就开着的拼多多标签页里没有它，于是「拼多多完全采不到信息」。现在采不到会自动补挂取数器并重载该页一次再采（同一页只自动重载一次），并把「页面有价却报未取到价格」这类口径矛盾一并修正
  • 标题多源兜底与探针（V0.9.13 起）：按 og:title → itemprop → meta → h1 → JSON-LD 依次取标题；整页只要有图片 / SKU / 属性 / 详情图 / 描述就不再因缺标题被判空，销量来源与评论数一并带回
  • 后台按目标市场自动测算：运费、平台扣点、其他成本 → 单件利润区间、毛利率、ROI 与「值得测试 / 谨慎测试 / 暂不建议」判定，头条取保守档
  • 填「预计采购量」就按对应档位算成本；不填按起订量档（最贵单价）算，并在界面写明是按哪一档算的
  • 妙手式编辑页：改标题、目标市场、预期售价、成本口径，保存即重算利润；标题可一键翻译成目标市场语言（服务端代跑）
  • AI 市场分析在服务端跑：输入带成本区间与档位口径，查不到的数字如实写「未知」，不编销量、搜索量、竞品价
  • 与官网同一枚账号令牌：会员、AI 点数、店铺归属与后台完全一致，不另造一套账号
安装四步
1. 下载并解压 zip，保留 market-scout-extension 文件夹位置不要移动（解压后第一层就能直接看到 manifest.json，选文件夹时别多进到子层）
2. 浏览器地址栏输入 chrome://extensions 回车 → 打开右上角「开发者模式」（Edge 为 edge://extensions；360 / 紫鸟 / 站斧同样有这一项）
3. 点「加载已解压的扩展程序」→ 选中第 1 步的 market-scout-extension 文件夹
4. 打开 1688 或拼多多的商品列表 / 详情页，页面右侧出现「ShopSage 选品助手」面板 → 用 ShopSage 官网邮箱登录 → 点「采集本页 / 采集到选品库」→「同步到后台」
采完在 ShopSage 后台「AI 商品选品 → 采集箱」看成本、利润与 AI 分析结果。
几点先说清楚，省得你以为没装上：① 采集 1688 / 拼多多时，浏览器里要已经登录该平台账号——插件只读页面已经显示的数据，不替你操作账号、不碰你的密码；② 列表页采集只有基础信息（标题 / 价格 / 主图），要 SKU、图片组、属性、件重尺、详情描述，请打开商品详情页再点「采集到选品库」；③ 插件更新过之后，已经打开的网页跑的还是旧代码，请回到商品页按 F5 刷新（或按 Ctrl+Shift+R 硬刷新）再采集；④ 本插件负责「采集 → 测算 → 编辑 → AI 分析」，刊登发布在后台完成，这里不宣传"一键发布"；⑤ 安装包不含账号与点数，账号请在 ShopSage 官网注册并邮箱验证。
